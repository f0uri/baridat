# بريدات

تطبيق Android بواجهة Flutter عربية للبريد المؤقت باستخدام [mail.tm](https://mail.tm). ينشئ التطبيق حساباً بعنوان وكلمة مرور عشوائيين ويحفظ بياناته محلياً، ويتابع الوارد كل ست ثوانٍ أثناء فتح التطبيق. أسماء النطاقات المتاحة تأتي من الخدمة؛ تغيير الاسم أو النطاق ينشئ صندوقاً جديداً ويحذف السابق لدى نجاح الطلب. رسائل العنوان السابق لا تنتقل إلى الصندوق الجديد.

عند الترقية من إصدارات المزود السابق سيُنشأ عنوان جديد؛ لن تنتقل الرسائل القديمة. لا تعرض التطبيق رسائل وهمية. الاعتمادية والتسليم يعتمدان على خدمة البريد والمرسل.

## البناء والاختبار

يتطلب Flutter 3.32.8 وAndroid SDK وJava 17:

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

اختبارات الوحدة تستخدم استجابات محاكاة ولا تثبت تسليم رسالة من Gmail أو تثبيت التحديث على جهاز. تُنشر الإصدارات عبر GitHub Actions باستخدام مفتاح التوقيع الثابت، ويحتوي `public/version.json` على معلومات التحديث.
