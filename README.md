# بريدات — بريد مؤقت

واجهة عربية داكنة للبريد المؤقت تستخدم **Guerrilla Mail API** فقط: إنشاء جلسة وعنوان عشوائي، تخصيص الاسم واختيار النطاق، نسخ العنوان، تحديث الوارد، قراءة الرسائل واستخراج رموز التحقق وروابط HTTPS. تُحفظ الجلسة ومعرّفات الرسائل محلياً؛ لا تنتقل رسائل الحسابات القديمة من المزودين السابقين إلى Guerrilla Mail، ولم تُحذف بياناتها المحلية.

## التشغيل والاختبار

```sh
npm ci
npm run dev
node --test
npm run build
```

تُغلّف أصول الويب في تطبيق Android عبر سير عمل GitHub Actions في `.github/workflows/build-apk.yml`. يُرسل جسر Android الطلبات عبر HTTPS مع User-Agent خاص بالتطبيق؛ على الويب يختار المتصفح User-Agent ولا يسمح لجافاسكربت بتغييره. يتصل المتصفح مباشرةً بالخدمة، ولذلك يعتمد عمل نسخة الويب على سماح الخدمة بطلبات CORS. لا يوجد خادم وسيط في هذا المشروع.

## سلوك البريد والخصوصية

- يُفحص صندوق الوارد كل 6 ثوانٍ **أثناء ظهور التطبيق**، وعند الرجوع إليه أو استعادة الاتصال. يُحدّث التطبيق الواجهة ويعرض تنبيهاً داخلياً؛ لا يوجد عامل خلفية أصلي أو إشعارات نظام عند إغلاق التطبيق، وقد يقيّد النظام عمله في الخلفية.
- قد تُنهي الخدمة جلسة أو تحذف الرسائل؛ التخزين المحلي لا يضمن بقاء العنوان أو محتواه لدى المزود. تغيير العنوان العشوائي ينشئ جلسة جديدة، وتغيير الاسم يستخدم الجلسة الحالية؛ لا تنتقل الرسائل القديمة تلقائياً.
- هذا البريد العام ليس خاصاً: لا تستخدمه لحسابات حساسة أو بيانات سرية. أسماء البريد المخصصة أو العشوائية ليست مضمونة الحصرية. تحقق من روابط التفعيل قبل فتحها.
- عند تأخر محتوى الرسالة تُعاد محاولة جلبه بعد ثانيتين ثم تُستخدم حقول النص أو المقتطف المتاحة. إذا لم يوفّر المزود أي محتوى، تظهر رسالة توضيحية بدلاً من الادعاء بوجود محتوى.
- تُستخرج الروابط والنص من HTML داخل عنصر خامل، ولا يُشغّل محتوى البريد كصفحة. تُخزّن رموز الجلسة محلياً؛ حذف بيانات التطبيق يحذفها. لا يمكن ضمان وصول الرسائل أو قبول عناوين البريد المؤقت من جميع المرسلين.

يمكن اختيار أحد النطاقات التسعة المعروضة؛ يُرسل النطاق بمعامل `site` وتُعرض استجابة الخدمة الفعلية. يعتمد نجاح تغيير النطاق وبقاء الرسائل على سلوك المزود، ولا يمكن ضمانه محلياً.
